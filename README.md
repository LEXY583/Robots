# Robots
The project to learn OO design concepts and MDI application development in Java

# Учебный проект «Robots»

## Что это такое?
Это учебное desktop-приложение на **Java (Swing)**, разработанное в рамках изучения объектно-ориентированного программирования и создания многодокументных интерфейсов (**MDI**).

Программа позволяет управлять виртуальным роботом на плоскости. **Робот умеет:**
- Перемещаться в указанную точку;
- Оставлять за собой след;
- Автоматически рисовать геометрические фигуры (*круг, квадрат, треугольник*).

---

## Основные возможности
- **Управление мышью:** легкая установка целей и рисование прямо на поле.
- **Два режима работы:**
    - *Движение к точке*
    - *Рисование фигуры*
- **Отображение следа:** визуализация траектории движения робота.
- **Многооконный интерфейс (MDI):**
    - *Игровое поле* — симуляция и управление
    - *Окно координат* — текущее положение и параметры
    - *Окно логов* — протокол работы программы
    - *Музыкальный плеер* — фоновое аудиосопровождение
- **Персонализация:** сохранение и восстановление положения и размеров окон между запусками.
- **Локализация:** полностью русскоязычный интерфейс.

## Архитектура
Приложение построено по принципу **разделения ответственности**:

- **Модель** (`RobotModel`) — хранит состояние робота (*координаты, направление, текущий режим, след и маршрут фигуры*) и содержит логику его движения.
- **Представление** (пакет `gui`) — отображает информацию пользователю и принимает команды.
- **Связь** между моделью и окнами реализована через паттерн **Observer**: при любом изменении состояния робота все окна автоматически обновляются.

## Для кого этот проект
Проект предназначен для студентов, изучающих:
- Основы объектно-ориентированного программирования (ООП);
- Работу с графической библиотекой **Java Swing**;
- Архитектуру многодокументного интерфейса (**MDI**);
- Шаблоны и паттерны проектирования (*Observer, Listener, Controller*);
- Командную разработку.

---

## Заключение
Проект **Robots** демонстрирует применение основных принципов ООП, работу с библиотекой Swing и организацию кода в учебном командном проекте.
